# Amaranthine — Omarchy Theme

A **black & purple neon** theme for [Omarchy](https://omarchy.org/). Deep violet-tinted blacks with a neon magenta accent — harmonious from the top bar to the terminal.

## Installation

Install via **Install > Style > Theme** in the Omarchy menu, then paste:

```
https://github.com/yks777/omarchy-amaranthine-theme
```

Or from the command line:

```bash
omarchy theme install https://github.com/yks777/omarchy-amaranthine-theme
```

Then apply it:

```bash
omarchy theme set amaranthine
```

## What's Included

| Asset | Description |
|-------|-------------|
| `colors.toml` | Dark-mode color palette (black & purple neon) |
| `icons.theme` | Icon theme reference (Yaru-purple-dark) |
| `backgrounds/` | Purple wallpaper collection |

Everything else — terminal, btop, Chromium, Hyprland, Neovim, VSCode, top bar, menu, notifications, OSD and lock screen — is generated automatically from `colors.toml`.

## Color Palette

| Role | Hex |
|------|-----|
| Accent | `#C724FF` |
| Background | `#08010D` |
| Foreground | `#E8D5FF` |
| Selection | `#3D0066` |
| Muted | `#6E4990` |

## Backgrounds

The theme ships with a set of purple-themed wallpapers in `backgrounds/`. Pick one with `Super + Ctrl + W`.

## Requirements

- [Omarchy](https://omarchy.org/) installed and configured
